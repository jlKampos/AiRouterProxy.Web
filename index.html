Your coding agent talks to the models.

AiRouterProxy is a fail-closed HTTPS gateway between your local AI coding agents and the model providers. It authenticates every caller, routes by prefix, rate-limits per client, streams SSE back — and redacts secrets before anything goes upstream.

One small Windows service. A pipeline that never forwards a body it could not inspect.

✧Secret redaction

OpenAI, Anthropic, GitHub, AWS, Hugging Face, PyPI, Docker, Stripe, SendGrid, Azure, databases… masked with a fixed •••••• before the request goes out.

◎Fail-closed inspection

Only bodies that pass the content-type policy and JSON parsing are ever forwarded. Unknown type → 415, invalid JSON → 400, oversized → 413.

⚿Auth with keys just for you

Bearer LocalKey or a full LocalKeys list for rotation. Wrong key, wrong length, brute-force attempts — all refused and logged (never the key value).

⇄Multi-upstream routing

Longest-prefix routes.json: default route to your AI Router, /openrouter to OpenRouter — each with its own key and allowed-path guards.

↯Rate limit + lockout

Per-IP windows with 429 + Retry-After, and a real lockout after repeated failures. Floods never reach your upstream.

≋SSE streaming

OpenAI chat, OpenAI responses, Anthropic and generic protocol adapters — tokens stream back to your agent exactly as they come in, redacted and annotated.
